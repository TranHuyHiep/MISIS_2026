# Домашние задания

**`hw_variant.py`** выдаёт ваш вариант ДЗ. Нажмите на файл, потом **Download raw file** (стрелка вниз над кодом) и сохраните его в папку своего проекта, рядом с `pyproject.toml`. Запускать из этой папки, в терминале VS Code:

```bash
uv run hw_variant.py ваш-github-логин        # ДЗ1 и ДЗ2: два блока констант
uv run hw_variant.py ваш-github-логин hw3    # ДЗ3: папка hw3/logs/ и блок констант
```

Без uv (Miniforge): `python hw_variant.py …`.

Для одного логина скрипт всегда выдаёт одно и то же. Блок вставляете в самое начало `hwN/main.py` целиком, от `# === ВАРИАНТ ===` до `# === КОНЕЦ ВАРИАНТА ===`, и руками его не правите.

**`README_шаблон.md`** — заготовка для `README.md` в корне вашего репозитория, с разделами «Мои решения» и «Где помогал ИИ».

Условия заданий — в тетрадках лекций: ДЗ1 и ДЗ2 в L2, ДЗ3 в L3.
